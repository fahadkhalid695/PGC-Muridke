# 🎨 PGC Color Scheme

This document outlines the color palette used throughout the website, matching your institution's logo.

## Primary Colors

### Deep Blue (Primary)
- **Hex:** `#002B5B`
- **Usage:** Main headings, navbar (scrolled), primary buttons, text emphasis
- **Represents:** Trust, authority, professionalism

### Bright Red (Accent)
- **Hex:** `#E50914`
- **Usage:** Call-to-action buttons, hover states, highlights, active links
- **Represents:** Energy, passion, action

### White
- **Hex:** `#FFFFFF`
- **Usage:** Backgrounds, text on dark backgrounds, cards
- **Represents:** Clarity, cleanliness, simplicity

## Secondary Colors

### Gray Shades
- **Light Gray:** `#F9FAFB` - Section backgrounds
- **Medium Gray:** `#6B7280` - Secondary text
- **Dark Gray:** `#374151` - Body text

## Gradients

### Primary Gradient
```css
background: linear-gradient(90deg, #002B5B, #E50914);
```
Used in: Hero sections, CTA banners, footer accents

### Subtle Gradient
```css
background: linear-gradient(to bottom right, #002B5B, #E50914);
```
Used in: Cards, feature boxes, hover effects

## Usage Guidelines

1. **Primary Blue** should dominate the design (60%)
2. **Accent Red** should be used sparingly for emphasis (10%)
3. **White/Gray** for balance and readability (30%)

## Accessibility

All color combinations meet WCAG 2.1 AA standards for contrast:
- White text on Primary Blue: ✅ Pass
- White text on Accent Red: ✅ Pass
- Dark Gray text on White: ✅ Pass
